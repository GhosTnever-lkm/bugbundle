# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not post real crash logs, credentials, or private data in a public issue. If private reporting is unavailable, contact the maintainer through the GitHub profile before sharing technical details publicly.

## Scope notes

BugBundle processes files locally in the user's browser. Redaction is best-effort and must not be described as a guarantee that a report contains no secrets. Treat selected log content as untrusted input and keep all previews and exports escaped or safely encoded.
